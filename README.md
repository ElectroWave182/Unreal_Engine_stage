# DT4PROD

Ce projet Unreal Engine est le mélange des travaux d'Enzo CAUSSE et de Osée-Thefort DJIOKENG-KOUAHOU, respectivement sur les thématiques de création d'un modèle virtuel d'un bras robot de la plateforme S.mart Operation Management (OM), accompagné d'outils de création de liaisons cinématiques \[ENZO], et d'une recréation visuelle de la même plateforme via gaussian splatting \[OSÉE]. Cela dans le but de créer un jumeau numérique de la plateforme OM pour un usage dans le cadre de TPs.
Ce projet s'inscrit dans le cadre de l’appel Idex pédagogique.


### Instructions

* Installer Node-RED, et l'ajouter aux variables d'environnement système :
https://nodered.org/docs/getting-started/local ;
* Lancer `dt4prod.exe` ;
* Aller à l'adresse `localhost:1880` sur navigateur (il sera alors possible de modifier le script Node-RED) ;
* Cliquer sur le menu à tiroir en haut à droite, et sélectionner "Import" ;
Cliquer sur "select a file to import", et choisir le fichier `node-red/flows.json`.
